# Library Management System

This is a web-based **Library Management System** that allows users to manage books, borrow and return books, and perform other library-related operations. The system supports two types of users: **Librarians** and **Regular Users**.

---

## Features

### For Librarians:
- Add new books to the library.
- Delete books from the library.
- View all borrowed books and their due dates.
- Manage the library's book inventory.

### For Users:
- Browse available books.
- Borrow books and view their due dates.
- Return borrowed books.
- Search for books by title, author, or genre.

### General Features:
- User authentication (login and registration).
- Role-based access control (Librarian vs. User).
- Persistent data storage using `localStorage`.
- Responsive design for better user experience.

---

## Technologies Used

- **HTML**: For structuring the web pages.
- **CSS**: For styling the application.
- **JavaScript**: For implementing the functionality.
- **Bootstrap**: For responsive design and UI components.
- **LocalStorage**: For storing user and book data persistently.
